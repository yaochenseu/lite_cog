# Lite3 导航操作

## 1. 启动 Mid360 雷达

打开终端 1：

```bash
cd /home/ysc/lite_cog/system/scripts/lidar
bash start_livox.sh
```

保持终端运行。可检查点云：

```bash
source /opt/ros/noetic/setup.bash
timeout 5 rostopic hz /rslidar_points
```

正常频率约为 `10 Hz`。

## 2. 启动导航

让机器狗停在建图起点，并保持建图开始时的朝向。打开终端 2：

```bash
cd /home/ysc/lite_cog/system/scripts/nav
bash start_nav.sh
```

保持终端运行。在 RViz 中确认当前位置与实际位置一致后再发送目标。

## 3. 语义导航

打开终端 3：

```bash
cd /home/ysc/lite_cog/system/scripts/nav
./goto --list
```

导航到指定位置：

```bash
./goto hall
./goto room
./goto door
```

取消当前导航：

```bash
./goto --cancel
```
## 4.新增语义点
1. 在 RViz 设置：

  Global Options → Fixed Frame → map

  2. 新终端监听点击位置：

  source /opt/ros/noetic/setup.bash
  rostopic echo /clicked_point

  3. 点击 RViz 顶部的 Publish Point，再点击地图上的目标位置。输出类似：

  header:
    frame_id: "map"
  point:
    x: 2.35
    y: -1.40
    z: 0.0

  使用 Publish Point 只发布位置；不要用 2D Nav Goal 采集，以免运行中的导航收到目标并开始移动。

  4. 编辑已有语义点文件：

  nano /home/ysc/lite_cog/system/map/waypoints.yaml

  在已有 waypoints: 下添加一个名字，例如 desk，与 hall、room 同级：

    desk:
      type: point
      orientation_mode: any
      position:
        x: 2.35
        y: -1.40
        z: 0.0
      orientation: null
      yaw: null
      source_topic: /clicked_point

  将 X、Y 换成实际输出。orientation_mode: any 表示不要求终点朝向。

  按 Ctrl+O、回车保存，再按 Ctrl+X 退出。检查是否读到：

  cd /home/ysc/lite_cog/system/scripts/nav
  ./goto --list

  这样便记录了语义点 desk。当前 goto 用于原来的 move_base 导航，尚未适配 SCAN。
